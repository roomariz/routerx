# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial release of RouterX CLI tool
- Chat command for interacting with AI models
- Models command for listing available AI models
- Code command for code generation, explanation, fixing, and review
- Streaming responses for chat interactions
- File saving capabilities for chat and code outputs
- Model filtering by free/paid status and search keywords

### Changed
- Renamed from minimax-cli to routerx
- Enhanced README with detailed documentation
- Added comprehensive inline comments to source code
- Created contribution guidelines
- Added code of conduct
- Added changelog

### Fixed
- Improved error handling for API responses
- Better fallback mechanisms for rate-limited models
- Proper environment variable handling for API keys

### Removed
- Previous minimax branding and references
